# UnityMirrors
Perspective correct mirrors for Unity

## Limitations
Currently doesn't support proper recursion. 

Mirrors only render if within the view frustum, so no infinite corridors either.

### Built in Unity 2022.3.62f1

To install package, use the following git URL in the Unity package manager:
> `https://github.com/absoluteSpacehead/UnityMirrors-URP.git?path=Assets/Package`
